# momo-plugin

面向 TRSS-Yunzai 的娱乐互动插件。功能按文件维护，由统一入口加载；发送 `momo帮助` 或 `#momo帮助` 查看当前成功加载且启用的功能，群聊和私聊均返回一个合并转发聊天记录卡片，标题、功能分类和使用说明各自独立成条。

## 安装与升级

1. 将完整目录放在 TRSS-Yunzai 的 `plugins/momo-plugin/` 下，也可改目录名；不要只复制 apps 文件。
2. 在插件目录运行 `npm install --omit=dev --ignore-scripts`（或使用 pnpm 安装）。依赖为 yaml、lodash；plugin、Bot、redis、segment、logger 及截图接口由 TRSS 提供。
3. 重启 TRSS，查看“已加载 11 个模块”日志；单模块失败会打印具体错误，不阻断其他模块。
4. 若曾把 CatRate.js、LunchRec.js、momoSleep.js 单独装到云崽的热加载目录，请移除那些旧副本再重启，避免重复响应和旧定时器残留。

升级时保留 `config/momo.yaml`、`config/battle.yaml`、`resources/poke/` 和修改过的 `resources/yaml/`。不要通过整个目录替换覆盖个人配置。GitHub 源码包不包含测试文件、旧代码备份、node_modules、个人配置及上传的戳一戳图片。

## 锅巴后台配置

安装并启动 Guoba-Plugin 后，在其插件配置页面选择 **momo 插件**。不安装锅巴也能按默认值运行。

- 决斗、转生、歌曲、点歌、抽签、写作、猫娘指数、吃什么、早晚安、戳一戳与图片管理均有独立功能开关。戳一戳和图片管理共享同一个开关。关闭功能时主人也不能使用；帮助始终可用。
- 决斗与戳一戳冷却单位为秒，转生及歌曲冷却单位为分钟。0 表示不设冷却；每日抽签、猫娘指数和晚安五小时重复限制仍按原规则执行。
- 决斗目标分数默认 13，可设 1-1000 的整数。
- 专用转生群默认留空，所有群和私聊使用 `preborn.yaml` 公共池；填入群号后，仅该群使用 `reborn.yaml` 专用池。新发布包中两份基础 YAML 内容相同，已有安装的自定义文件须保留。更改分流只改变后续访问的记录，不搬迁或合并历史记录。
- 「公共池额外角色」「专用池额外角色」在锅巴点击列表后添加角色名与身份介绍。公共新增同时进入两池，专用新增仅进入专用池。可以修改或删除新增条目，不会改写基础 YAML。角色名和介绍不能为空，同一有效角色池不能重名；保存失败不覆盖原配置。
- 保存后后续消息立即使用新配置，帮助随之更新，不需要重启；已经开始的请求按读取时的配置完成。
- 戳一戳已建立的短期冷却键按原过期时间结束，下次建立冷却使用新时长；设为 0 会立即跳过冷却。

首次后台保存时创建用户配置 `config/momo.yaml`，该文件已加入 .gitignore。未设置新比分之前读取旧 `config/battle.yaml`；后台保存后比分由 momo.yaml 管理。手工编辑 momo.yaml 也会在后续读取时生效；无效配置会记录错误并使用进程内上次有效配置，首次启动无有效配置时使用默认值。

基础角色、签文、歌单与写作模板继续编辑 `resources/yaml/`。新增转生角色可直接在锅巴配置；删除基础角色仍需修改对应 YAML。图片继续通过主人指令管理。

公共池＝preborn.yaml＋公共额外角色；专用池＝reborn.yaml＋公共额外角色＋专用额外角色。两份额外列表保存在个人配置 config/momo.yaml，基础文件不会被后台保存覆盖。升级保留已保存的专用群号和额外角色；未保存群号时采用新版空默认值。角色名用于关联历史次数，修改名字按新角色统计；删除角色不会删除其旧次数，但记录列表仅显示当前池内角色。

## 全部命令（默认设置）

| 指令或操作 | 作用和限制 |
| --- | --- |
| momo帮助 / #momo帮助 | 当前可用功能的合并转发聊天记录 |
| momo决斗 [@对手] | 不指定对手时对战机器人；发起冷却 120 秒 |
| momo转生 | 随机角色；冷却 75 分钟 |
| momo转生记录 | 查看转生统计；冷却 5 分钟 |
| momo抽签 | 每日一次 |
| 今日猫娘指数 | 每日一次；比较上次检测结果 |
| momo点歌 [编号] | 指定编号，或不填/只填空白时随机点歌 |
| momo歌单 | 编号歌单图片，截图失败时返回文字 |
| momo歌曲推荐 | 随机推荐；冷却 5 分钟 |
| momo歌曲列表 | 查看全部歌名 |
| momo歌曲搜索 歌名 / momo歌曲查找 歌名 | 完整歌名，忽略大小写；成功查询后冷却 6 分钟 |
| momo写作 模板词 内容 | 替换模板，内容为不含空格的一个参数 |
| momo的写作帮助 | 查看模板关键词 |
| 今天吃什么 | 也支持早上吃什么、中午吃什么、晚上吃什么、凌晨吃什么、宵夜吃什么、现在吃什么 |
| 早安 / 晚安 | 仅群聊，记录作息与排名 |
| 戳一戳机器人 | 随机本地图片，同会话同用户冷却 7 秒 |
| #poke上传 + 图片 | 仅主人；同一条消息带一张图片 |
| #poke列表 | 仅主人；最多展示前 50 张 |
| #poke删除 序号或文件名 | 仅主人；先查列表再删除 |

主人可跳过决斗、转生、转生记录查询、歌曲推荐和歌曲搜索的冷却。戳一戳、晚安重复限制以及两个每日次数限制对主人也生效。原有每日抽签和猫娘指数仍以服务器当地日期计日；希望按北京时间使用时，请将 TRSS 服务器时区设为 Asia/Shanghai。

## 早晚安与数据兼容

- 晚安同义词：晚安、睡了、睡觉、去睡了、我睡了、我要睡了。北京时间 17:00 至次日 09:00（不含 09:00）记录睡眠，其他时段仅提醒；五小时内重复晚安不计数。
- 早安同义词：早安、早、起床、醒了、我醒了、早上好。北京时间 04:00 至 11:00（不含 11:00）记录起床；00:00-04:00 提醒继续睡，11:00-14:00 提醒起晚，14:00 后提示注意健康。
- 排名周期为北京时间当天 13:00 至次日 13:00（不含终点），按群独立统计。周期排名键及个人起床排名保存七天；不创建定时器、不扫描 Redis。重复早安沿用首次排名，并发早安也只计一次。
- 升级后的作息排名重新起算，旧排名不删除、不迁入。继续读取旧个人入睡时间，成功起床后按原行为清理该次个人睡眠记录。只有非负且小于 16 小时的睡眠时长会展示。
- 决斗、转生、猫娘指数等旧 Redis 记录沿用。专用转生池使用原 momo 前缀及按用户记录；公开池使用原 pmomo 前缀及按群/用户记录；私聊继续沿用原 undefined 群号段以兼容历史记录。

## 维护与验证

新增功能时在 `model/registry.js` 登记模块和帮助说明；如需后台开关，在 `model/config.js` 登记配置，再将登记项的 feature 对应到配置。模块导出类名应与文件名一致。


上线前还应在真实 TRSS 中验收锅巴页面保存、群/私聊通知、图片上传删除、决斗截图和歌曲合并转发。缺少字体时现有图片模板会使用系统回退字体；帮助菜单不依赖截图。
